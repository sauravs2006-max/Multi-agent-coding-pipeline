Write a function merge_intervals(intervals) that takes a list of [start, end] pairs
(integers, start <= end, in any order) and returns a new list of merged intervals sorted by
start. Overlapping intervals are merged, and so are intervals that just touch, so [1, 4]
and [4, 5] become [1, 5]. Return a list of [start, end] lists and don't modify the input.
