Write a class LRUCache with:
- LRUCache(capacity): capacity is a positive int, raise ValueError if it is less than 1.
- get(key): return the value for key, or -1 if the key is not in the cache.
- put(key, value): insert or update the key. If that takes the cache over capacity,
  evict the least recently used key.
Both get (when the key exists) and put count as using a key. Both should be O(1).
